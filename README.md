# Relay Stream Portal

WordPress plugin: customer portal + `/wp-admin` management dashboard + TVPlus Panel API integration for authorized streaming subscriptions. WooCommerce billing, Elementor Free widgets (or shortcodes), English/Arabic (RTL).

* Plugin source: [`relay-stream-portal/`](relay-stream-portal/)
* Installable ZIP: [`dist/relay-stream-portal.zip`](dist/relay-stream-portal.zip) (rebuild with `relay-stream-portal/bin/build-zip.sh`)
* Docs: [setup & operations](relay-stream-portal/docs/README.md) · [API mapping](relay-stream-portal/docs/API-MAPPING.md) · [Elementor walkthrough](relay-stream-portal/docs/ELEMENTOR-WALKTHROUGH.md) · [test results](relay-stream-portal/docs/TEST-RESULTS.md)

Live provider mode is off by default and has only been tested against a fixture; verify it on your own panel first (see the API mapping checklist).
