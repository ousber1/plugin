# HO CREATIVE — POS & ERP

Logiciel de gestion (point de vente + ERP) conçu pour une agence marocaine d'impression,
de publicité, de design et de communication. Interface entièrement en français, devise MAD (DH).

**Stack :** PHP 8.2+ · MySQL/MariaDB · PDO · Bootstrap 5 · JavaScript natif / AJAX.
Aucune dépendance Composer : compatible hébergement mutualisé cPanel.

## Démarrage rapide

1. Copiez les fichiers sur le serveur (ex. `public_html/erp/`).
2. Créez une base MySQL vide et un utilisateur (cPanel › Bases de données MySQL).
3. Ouvrez l'URL du site : l'assistant `/install/` vous guide.

Détails : [docs/INSTALLATION.md](docs/INSTALLATION.md)
